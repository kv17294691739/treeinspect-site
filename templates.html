Sample templates

Excel files you can download, edit and import into Tree Inspect. Each one shows what the sheets look like and what every column means.

Downloads
  1. Project template – data fields, export settings and SOR
  2. SOR list – schedule of rates for quoting PRO
  3. Species catalogue – common and scientific names
  4. Project import – a whole project with tree data PRO
The files open in Excel, Google Sheets, LibreOffice or Numbers. Keep the sheet layout, change the content, then import the file on your phone (save it to Files or Drive first). All names and prices in the samples are made up. The app’s import screens also have their own Download sample button.

The pictures below are screenshots of the sample files open in LibreOffice Calc.

1. Project template

⬇ Download project template sample TreeInspect_project_template_sample.xlsx · 8.7 KB

A survey form with 10 fields (within the Free limit), two Excel export orders and an 8-item SOR list. Import: Projects › Project templates › Import templates › Choose file. In Match template sheets choose Fields = Data fields, Export settings = Export settings, SOR = SOR and Read me = Ignore. The template is named after the file. See Templates and fields.

Sheet “Fields” (required)

PartWhat goes there
Row 1 – titleThe field name shown on the tree form and used as the Excel column title, e.g. Height (m). One field per column.
Row 2 – typetext, number, dropdown, multidropdown, checkbox, checklist, date or gps (location). Capitals and spaces are ignored.
Row 3 onwards – optionsFor dropdown, multi dropdown and checklist fields: one option per row. The list ends at the first empty cell. Leave blank for other types.
{{num}} in an optionBecomes a number box on the tree form, e.g. Reduce crown by approximately {{num}}m all over.

The sample’s columns:

ColumnTypeMeaning / options

Age classdropdownYoung, Early-mature, Mature, Over-mature, Veteran.

RecommendationschecklistTick any: No action required; Remove major deadwood; Lift crown to give {{num}}m clearance over footpath; Reduce crown by approximately {{num}}m all over; Fell to ground level and treat stump; Sever and clear ivy from the stem.

Tree ID, tree species and inspection date are always added by the app, so they are not listed in this sheet.

Sheet “Export settings” (optional)

PartMeaning
Row 1The name of the export order. The first column becomes the default.
Rows belowThe columns to export, top to bottom in order. Use a field title from the Fields sheet, or ID, Species, Inspection date, Project, Project ID, Client, Address, an SOR column title or Price. Names the app does not recognise are skipped.
Default (sample)A full survey: ID, species, date and every field.
Works schedule (sample)ID, Species, Recommendations, Work priority, and the SOR Code, Description and Price.

Sheet “SOR” (optional) PRO

Same columns as the SOR list sample. It is saved as an SOR structure named after the sheet, and the template’s quoting method is set to SOR. Quoting needs Pro.

2. SOR (schedule of rates) list PRO

⬇ Download SOR list sample TreeInspect_SOR_list_sample.xlsx · 6.3 KB

Eight sample work items with prices. Import: open a project › Project settings › set the quoting method to SOR › Import spreadsheet, then choose the SOR rates sheet if asked. Importing replaces the project’s current SOR list. See Project settings and SOR.

ColumnWhat it means
CodeA short item code, e.g. TW01. The first column is shown as the code on the tree form.
CategoryA group for the item, e.g. Pruning, Felling, Stumps.
DescriptionThe work, e.g. Crown lift to 5m. Shown under the code on the tree form.
UnitHow the item is counted, e.g. Per tree, Per stump, Per load.
PriceThe unit price used for quoting. Exactly one column title must contain the word “Price”. 85, 85.00 and £85 all work.

You can rename, add or remove the other columns; each becomes a field on every SOR item. Files must be .xlsx or .csv.

3. Species catalogue

⬇ Download species catalogue sample TreeInspect_species_catalogue_sample.xlsx · 6.1 KB

Sixteen common UK species. Import: Projects › Species catalogue › Import from Excel, then choose the Species sheet. Species already in your catalogue are not added twice. Many of these are in the built-in list already, so use the file as a pattern for your own species. See Species catalogue.

ColumnWhat it means
A – Common nameThe everyday name, e.g. English oak. One species per row. A header row is skipped.
B – Scientific nameThe botanical name, e.g. Quercus robur. Optional. Shown in italics in the app and in exports.

4. Project import PRO

⬇ Download project import sample TreeInspect_project_import_sample.xlsx · 8.0 KB

Creates a whole project with five trees. Creating a project from a spreadsheet needs Pro. Import: Projects › Import backup › Choose file. In Match sheets choose Tree data = Tree data, Fields = Field structure, Read me = Ignore, then enter a project name. See Import, export and backups.

Sheet “Tree data”

ColumnWhat it means
IDThe tree ID, e.g. T-001. Also recognised as Tree ID or Tag. Optional: blank IDs are numbered automatically.
Tree speciesThe species, e.g. English oak (Quercus robur). Also recognised as Species.
Inspection dateAlso recognised as Date. Optional: a blank date uses the import date. Write dates as text, e.g. 2026-09-14.
Height (m) … Re-inspect periodEvery other column is stored under the field with the same title in the Fields sheet. Dropdown values should match an option; checklist values use the option text.

Sheet “Fields”

Same format as the project template Fields sheet: row 1 titles, row 2 types, options below.

Free version limits apply to imported templates: the first 10 custom fields and the first 8 options per list are kept. See Pro and Free limits.
