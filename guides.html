Quick start

  1. Create a project and enter the client and site details.
  2. Attach a site plan in project settings.
  3. Check the fields you want to record, or import a sample template.
  4. Add trees, pin them on the plan and add photos.
  5. Export to Excel, and keep a Full export as a backup.
